# 一键补全 LoRA 信息：需求与实现范围

## 需求来源

已读取 [issue #11](https://github.com/shigjfg/ComfyUI-Magic-Assistant/issues/11) 正文、全部 9 条评论和两张截图。

- 用户最初询问如何批量爬取 Civitai 信息；维护者随后提供了 README 中的独立工具。
- 讨论中的文件夹拖拽问题已由用户确认通过重建节点解决，与本次下载功能分开处理。
- 2026-10-01 用户反馈独立工具会重新下载已有信息，要求在强力 LoRA 加载器节点底部直接提供一键入口。
- 2026-10-02 维护者承诺下一版本加入。

核心需求是提供独立的本地 LoRA 信息批量管理弹窗，支持不同范围和使用目的，减少逐个打开编辑窗口的操作，并默认保留已经下载或手动编辑的信息。截图说明入口位置，不能据此把处理范围限定为当前节点。

## 使用行为

1. 在节点底部提供独立弹窗入口，默认浏览整个本地 LoRA 库；当前节点、节点文件夹也是可选快捷范围。当前节点范围包含禁用项，同一文件只处理一次。
2. 支持真实磁盘目录、是否包含子目录、文件名／路径搜索、只看待处理项及手动多选。显示各类信息已有／缺失状态，提供刷新列表、全选可见项和清除选择。
3. 沿用单个下载的四项选项：触发词 `.txt`、模型介绍 `.json`、预览图和推荐权重 `.log`，以及同目录／`magicloradate` 子目录保存设置。
4. 默认补全缺失信息。按类型同时检查 LoRA 同目录和 `magicloradate`；有介绍但没有预览时，只下载缺失部分。完整项在计算哈希和联网前跳过。已有空文件也受到保护。也可主动选择更新已有信息；开始前确认选中数量和内容类型，已有信息写回原位置，新信息按保存设置落盘。
5. 串行查询，显示当前文件、已处理数量及各项结果。停止后不开始下一项，当前文件完成后保留结果；已完成内容不会回滚。
6. 单项失败不阻断后续文件，支持只重试失败或部分失败的项。未找到 Civitai 记录与网络／写入失败分别显示。
7. 开始前显示范围、选中、需要处理及完整项数量。只下载当前筛选范围内勾选的文件，开始后冻结队列，隐藏的选择不会意外进入下载。
8. 下载结束刷新清单中的信息状态和预览，同步当前工作流中引用相关 LoRA 的节点信息字段，不自动替换工作流中的标签、权重、启用状态或排序。
9. 使用可拖动、可调整大小的独立浮窗，不加全屏遮罩；窗口打开或下载进行中仍可操作画布及其他节点。顶部筛选、左侧下载设置、右侧文件列表，下载结果按需展开。Esc 仅在窗口内部生效。

## 实现取舍

- 复用单个下载接口和现有文件读取规则；列表接口按需提供各类型本地信息状态。清单检查不计算哈希、不联网；扫描、哈希、网络和磁盘工作交给现有后台执行辅助函数，避免阻塞 ComfyUI 的事件循环。
- 保持现有 sidecar 格式：`.json` 在本插件中是可读介绍文本，`.log` 是含推荐权重的 JSON 文本。
- 不增加依赖、常驻下载服务或持久任务数据库。批量队列随弹窗存在；关闭页面后不会继续启动后续下载。
- 来源没有触发词、静态预览或推荐权重时，报告缺少该项，不生成虚假信息文件。因此再次补全时，仍可能查询这些确实缺失的项。
- 使用临时目标文件完成写入后再替换，避免下载或保存失败破坏已有内容。没有 OpenCV 时不会将视频伪装成图片保存。
- 仅使用已有 Civitai 查询方式，不增加密钥设置，也不复用 AI 服务的密钥。
- 同目录同名不同后缀的模型会共用信息文件。更新模式中，每组只能选择一个模型，避免同一套信息被不同模型反复覆盖；补缺模式仍保留已有文件。

## 验收重点

- 全库、真实目录、递归、搜索、当前节点与节点文件夹范围准确；当前节点包含禁用项、文件夹项且无重复。筛选与勾选共同决定下载范围，预检数量正确。
- 四种信息独立补缺，两个保存位置和已有 `.preview`／`.cover` 预览均受保护；完整项不联网。
- 查询失败、未找到、部分保存失败和来源缺少某种信息分别记录，后续文件继续执行。
- 停止不启动下一项，重试不重新处理成功项；刷新后预览和已保存信息可见，工作流参数保持原值。
- 原单个下载仍可使用，批量耗时工作不阻塞本地服务；写入失败保留原内容。
- 主动更新前明确确认数量和类型；更新原位置可被现有读取规则正确读到，默认补缺不会覆盖已有内容。列表刷新反映新增文件与下载后的信息状态。
